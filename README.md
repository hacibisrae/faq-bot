🤖 FAQ Bot – Intelligent Technical Assistant
A simple and interactive web-based chatbot built with Python and Flask, designed to answer frequently asked technical questions about software development and DevOps.

📌 About the Project
FAQ Bot is a rule-based chatbot that helps users find quick answers to common questions related to modern development tools and technologies.

The chatbot covers several technical topics:

🐙 Git & GitHub – Version control and repository management.
🐳 Docker – Containerization and Docker commands.
☸️ Kubernetes – Container orchestration basics.
⚙️ CI/CD – Continuous Integration and Continuous Deployment.
The main goal of this project is to provide a simple, accessible, and user-friendly technical FAQ assistant.

✨ Features
💬 Interactive chatbot interface.
⚡ Instant responses based on predefined rules.
📚 Multiple technical topics.
🐍 Built with Python and Flask.
🌐 Web-based interface.
🎯 Simple and lightweight architecture.
